# SVGTracker V38 — iPhone Shortcuts Setup

Основа: V37. Обновление выполняется ZIP-деплоем через SVGTracker Admin.

## Возможности

- Новая вкладка «Команды iPhone» в `Профиль → Настройки`, а также прямой переход `Финансы → Команды iPhone`.
- Пошаговое создание команды в приложении Apple «Команды», включая меню «Расход / Доход», выбор категории, ввод суммы, HTTPS GET/POST, Bearer-токен, дату и вывод подтверждения.
- Быстрая ссылка `shortcuts://create-shortcut` на официальный редактор Apple. На некоторых клиентах Telegram открытие пользовательских схем может блокироваться, поэтому указан ручной вариант.
- Новый API: `GET /api/shortcut/setup`, `POST /api/shortcut/token`, `POST /api/shortcut/revoke`. Только авторизованный Telegram Mini App или веб-сеанс с origin-проверкой (как в V37).
- Токен генерируется криптографически, хранится на сервере **только SHA-256 хеш**, показывается единственный раз при выдаче, не помещается в URL, локальное хранилище, аналитические события или логи. При выходе из экрана стирается из DOM и временной JS-памяти. Перевыдача отзывает предыдущий токен.
- Статус подключения проверяется по метаданным без возврата секретного токена.
- Существующие команды бота `/shortcut` и `/shortcut_revoke` остаются совместимы.
- Возможность добавить **настоящую** готовую iCloud-команду через переменную окружения `SVGTRACKER_SHORTCUT_ICLOUD_URL` (строгая проверка домена и пути). Без опубликованного валидного URL кнопка установки скрыта. Шаблон должен создаваться и публиковаться через Apple «Команды» (см. `deploy/SHORTCUTS_PUBLISHING.md`).

## Важно для админа

- На VPS остаются неизменными база данных, `config.py`, пользовательские файлы и ключи. Миграции таблиц не требуются — таблица `shortcut_tokens` уже есть.
- Адрес интеграции берётся из `SVGTRACKER_PUBLIC_URL` (по умолчанию https://starslix.ru). При другом домене укажи соответствующее значение в окружении сервиса.
- Двухсторонняя синхронизация финансов уже предусмотрена API предыдущих версий. POST сохраняет запись в SQLite и отправляет подтверждение в Telegram.
- Из-за ограничений Apple невозможно с сервера SVGTracker автоматически создать и молча установить полноценную команду. Ссылка `shortcuts://create-shortcut` открывает редактор, а не устанавливает готовую команду. Настоящая установка в одно нажатие возможна после публикации iCloud-шаблона.

## Проверка после деплоя

1. Войти в Telegram Mini App, открыть Финансы → Команды iPhone.
2. Создать ключ, сохранить его через кнопку, перезапустить экран: старый ключ не должен показываться.
3. Проверить через iOS «Команды» URL получения категорий и отправку расхода.
4. Убедиться, что расход появился в финансовой истории и подтверждение пришло от бота.
5. Выдать новый ключ: старый должен вернуть 401. Нажать «Отключить»: новый также должен вернуть 401.
6. На других аккаунтах статус и ключи не должны пересекаться.

## Локальная валидация

`python -m unittest discover -s tests -q` и `python -m compileall -q .`, `node --check script.js`.
Ограничение: из Linux невозможно проверить реальный системный импорт Apple Shortcuts или работу физической кнопки Action Button. Это проверяется пользователем на iPhone после установки.
