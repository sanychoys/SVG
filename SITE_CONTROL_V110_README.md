# Site Control v1.10 — Neon Blue / UI fixes

**Назначение:** визуальная корректировка v1.9 и исправление двух сценариев переключения интерфейса; бизнес-логика и API без изменений.

- Палитра: graphite `#080c11`, cyan `#35d7ff`, electric blue `#327cfa`, white `#f5fbff`.
- Фокус полей — один нижний cyan-индикатор вместо двойной рамки.
- Mobile drawer: blur overlay, dismiss on tap outside or Escape; исправлен конфликт устаревшего `left` со `transform`.
- Project workspace: вкладки отображаются взаимно исключительно, включая `platformUpdater` на вкладке «Файлы» только для внутренней платформы.
- Terminal: увеличены размеры ввода и вывода.
- Убраны пустые декоративные квадраты метрик.

`style.css` содержит новый блок `SITE CONTROL 1.10 — COBALT / ICE` в конце. `script.js` затронут только в UI-обработчиках. Версии ассетов: `sc1100`.

Подробные шаги и тесты — в `ИНСТРУКЦИЯ.txt` и `АУДИТ_И_ТЕСТЫ.txt`.
