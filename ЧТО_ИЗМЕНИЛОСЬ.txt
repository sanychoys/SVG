Site Control v1.12 — управление платформой, VPS и доменами

- Добавлен отдельный systemd-путь для установки ZIP из Mini App и сайта.
  Требуется однократная настройка на текущем VPS (см. ИНСТРУКЦИЯ.txt).
- Для первого обновления при сломанном systemd-run включён ручной безопасный
  установщик с бэкапом и автоматическим откатом, запускаемый по SSH.
- Новый VPS: возможность создать папку продукта автоматически на удалённом
  сервере после подключения SSH. Файлы остаются на клиентском VPS.
- Для клиентских проектов появилась вкладка «Домены»: DNS-проверка, список
  доменов и готовый пример Nginx-конфигурации.
- На собственном VPS появился «Обзор VPS»: CPU, RAM, swap, диск, uptime,
  версия ОС/Python, интерфейсы, состояние процесса.
- «Очистить RAM приложения»: Python GC, освобождение памяти только Site Control,
  не принудительное удаление кеша Linux и не трогает другие процессы.
- Все поля ввода получили минимум 16px во избежание zoom на iPhone.
- Текущая БД Site Control и Telegram-администраторы не заменяются.

Ограничения:
- Домен покупается пользователем, DNS редактируется у регистратора;
  выдачу HTTPS-сертификата и установку Nginx пользователь обеспечивает
  с правами на целевом VPS. Вкладка Домены не выдаёт ложное «готово».
- Без единовременной доверенной настройки серверного updater веб-процесс
  не может самостоятельно выдавать себе root-права.
- Управление произвольным shell в нашем VPS от root через браузер запрещено.
