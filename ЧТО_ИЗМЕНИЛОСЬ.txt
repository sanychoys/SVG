SITE CONTROL v1.19 — КОМАНДЫ И ОБНОВЛЕНИЯ

1. При нажатии «Выполнить команду» ручное поле очищается до получения ответа.
2. Убраны повторные окна подтверждения команд на собственном и клиентских VPS (сайт, Telegram Mini App, бот).
3. Root-доступ настраивается в «Команда» → «Настроить права»: отдельные галочки нашего VPS и клиентских VPS. Права проверяются сервером для каждого запроса.
4. В быстрые команды добавлены проверка версии Python, список пакетов и список доступных обновлений ОС. Для обновления системного Python вручную сначала оцените совместимость приложений.
5. Для сайта и Mini App добавлен запуск проверенного ZIP через уже работающий root-исполнитель Site Control без вызова systemd-run самим веб-приложением. Для Telegram применяется тот же валидатор, очередь и откат.
6. Добавлены технические проверки установки, ролей, синтаксиса и адаптивности.
7. Существующие файлы базы данных, секреты и администраторы не включены в архив. Корневые документы справки обновляются с новой версией.

ВАЖНО: саму v1.19 впервые установите через работающий Telegram-бот либо через SSH, поскольку предыдущая версия веб-интерфейса не умеет обращаться к новому пути установки. После обновления проверьте сайт/Mini App.
Публикация на настоящем VPS и запуск systemd-root исполнителя локальными тестами не подтверждены. Не устанавливайте поверх работающей системы без бэкапа.
