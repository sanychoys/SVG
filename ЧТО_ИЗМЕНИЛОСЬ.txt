SITE CONTROL v1.7 — ИЗМЕНЕНИЯ
24.10.2026

1. MINI APP
- В /start главного Telegram-бота для администратора создаётся защищённый одноразовый билет входа. Время действия билета — 90 секунд; открыть необходимо свежую кнопку. После использования билет недействителен.
- При корректной подписи Telegram используется штатная авторизация initData; при её несовпадении одноразовый билет обеспечивает автоматический вход без дополнительного подтверждения.
- Вход без подписи И без билета запрещён; Telegram ID из браузера не считается доказательством прав.
- Билет удаляется из адресной строки ещё до открытия панели. Резервная сессия хранится 2 часа в Secure HttpOnly-cookie. Администраторы и право доступа проверяются повторно.

2. ЛОГИ
- По умолчанию последние 30 событий за 24 часа; полный traceback остаётся вместе со свежей ошибкой.
- В панели показывается время устройства; скачиваемый через панель TXT уже конвертирован в его часовой пояс.
- У администратора, открывшего панель, часовой пояс запоминается. При /logs Telegram отправляет время в последнем зарегистрированном поясе; до первого входа в панель — UTC.
- Старые 404 маршрутов бывшего SVGTracker не засоряют новые журналы.
- Обновлено отображение серверных логов journalctl за последние сутки.

3. КОНСОЛЬ И VPS
- Устранена ошибка Python 3.14 preexec_fn: понижение привилегий выполняется через параметры subprocess user/group.
- SSH-проверка поддерживает повторяющиеся ответы, ED25519, ECDSA и RSA. Отпечаток всё равно нужно вручную сверить на своём VPS.
- Непонятные ошибки при отсутствии SSH стали явными и краткими; полные трассировки остаются в служебном журнале.

4. ДИЗАЙН
- Чистая монохромная палитра, спокойная типографика, простая навигация, единая геометрия элементов.
- Снижено число градиентов и декоративных элементов, добавлены ненавязчивые переходы.
- На мобильном экране вкладки проекта расположены в прокручиваемой строке.

5. ДАННЫЕ
- Существующая база Site Control и файл со списком администраторов не входят в ZIP и НЕ заменяются.
- Основной ID 382257126 сохранён; второй администратор остаётся в прежнем реестре VPS.
