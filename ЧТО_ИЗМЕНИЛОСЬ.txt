SITE CONTROL v1.6 — СПИСОК ИЗМЕНЕНИЙ
Дата сборки: 24.10.2026

1. Mini App: увеличено время загрузки Telegram SDK, добавлена повторная проверка и понятное сообщение о причинах отказа. ID владельца 382257126 остаётся главным. Подтверждённый администратор заходит без обычной браузерной авторизации. Подпись initData проверяется на сервере; проверки по введённому ID недостаточно.
2. Проекты: перенос в архив, возврат из архива, окончательное удаление после ввода slug и отключения связанных VPS. Удаление записи из системы НЕ стирает файлы на VPS клиента. Файловые копии остаются для возможного восстановления.
3. «Наша платформа»: собственный VPS виден в консоли сразу, без добавления SSH-сервера. Команды выполняются с ограниченными правами текущего сервиса, ручные — только с подтверждением.
4. Логи: текст можно открыть прямо во вкладке, скопировать и скачать TXT. Для клиентских проектов введены отдельные журналы Telegram-событий, заявок и публикаций. Логи VPS получаются по привязанному SSH-соединению. Ошибки публикации сохраняют traceback.
5. Управление сервером: переименованы непонятные поля, подробный пошаговый FAQ про SSH-ключи, отпечатки серверов, DNS, домены и HTTPS.
6. Интерфейс: тёмная чёрно-белая тема по референсам; добавлен предоставленный владельцем логотип; улучшены кнопки, навигация, вкладки, мобильная компоновка, состояния полей и сдержанные анимации.
7. Telegram: сохранены только /start, /status, /logs; добавлена принудительная настройка командного меню и командных областей администраторов при запуске службы.
8. Администраторы: форма добавления компактнее. ID остальных администраторов сохраняются в отдельном файле вне обновления.
9. Инструкции: отдельная вкладка FAQ и подробный текстовый файл в ZIP.

СОВМЕСТИМОСТЬ
Архив рассчитан на действующий механизм ZIP-деплоя Site Control v1.5 / мост совместимости V48.
Технические имена svgtracker.service и /var/www/SVG сохранены для работающего старого установщика. Это не восстановление старого трекера.
Существующую базу sitecontrol.db, admins.json, токены, SSH-ключи, Nginx и конфигурацию сервера архив не содержит и не перезаписывает.

ОГРАНИЧЕНИЯ
- Реальные Telegram, SSH и установка на VPS не проверены из локальной среды.
- Автоматическая настройка DNS, Nginx, TLS и прав sudo не входит в v1.6.
- Перезапуск самой службы через собственный веб-процесс не включён: он может оборвать текущую операцию.
- Файловые бэкапы не заменяют копии внешних баз данных.
