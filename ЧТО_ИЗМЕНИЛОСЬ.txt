SITE CONTROL V1.2 — КРАТКО ОБ ИЗМЕНЕНИЯХ

1. Главный Telegram-бот: только /start, /status, /logs и /backup в меню команд.
   В /start добавлена inline-кнопка «Открыть Mini App».
2. Mini App: панель Site Control открывается внутри Telegram. Вход по проверенным
   данным Telegram для администраторов; обычный сайт сохраняет вход по коду.
3. Команда /status отправляет один TXT-файл с состоянием, временем последнего
   изменения и инструкцией. Полная ошибка включается в TXT, если она известна.
4. Команда /logs: два отдельных TXT-журнала — Telegram-бот и сайт/API.
   Обычные события краткие, traceback ошибки сохраняется целиком в журнале.
5. Дизайн панели: чёрный / белый / оранжевый, бирюзовый для статусов,
   улучшенная адаптация для смартфонов.
6. Старые файлы и старую БД трекера можно удалить отдельной подтверждаемой
   командой /cleanup_legacy после установки. До очистки создаётся архив.
   Действующие проекты и база Site Control не удаляются.
7. Изменения Site Control поставляются с инструкцией и этим TXT-файлом.

ОГРАНИЧЕНИЯ
- Это обновление программы, не проверенное на вашем реальном VPS.
- Домен и HTTPS в конфигурации сервера должны вести на панель Site Control.
- ZIP не переименовывает старый systemd-сервис и не перенастраивает Nginx.
- Старые серверные бэкапы сохраняются для восстановления; они не очищаются автоматически.
