SITE CONTROL v1.18 — ROOT БЕЗ ЛИШНИХ ПОДТВЕРЖДЕНИЙ И ПОДКЛЮЧЕНИЕ VPS С ТЕЛЕФОНА

1. Владелец Site Control (Telegram ID 382257126) исполняет разрешённые ROOT-команды нашего VPS сразу, без повторных окон подтверждения — в Mini App, веб-панели и Telegram-боте. Проверка подлинности пользователя и прав не отключена.
2. В «Администраторы → Настроить права» появился переключатель «Подтверждать root-команды». Владелец может включить/выключить его индивидуально. По умолчанию новым и существующим дополнительным администраторам подтверждения нужны. Настройки сохраняются в существующем реестре ролей вне ZIP.
3. То же поведение для клиентских VPS, подключённых по SSH под root: владелец выполняет без дополнительных подтверждений; у остальных администраторов действует индивидуальная настройка.
4. «Серверы → Подключить VPS» дополнен инструкцией и готовой командой выдачи доступа по публичному SSH-ключу для консоли хостинг-провайдера, а также вариантом cloud-init для первого запуска Ubuntu. Всё можно скопировать и сделать с телефона.
5. Исправлены проверки прав в API и Telegram для удалённых root-подключений, настройки редактора прав и адаптивность мастера VPS на узких экранах.
6. НЕ изменены структура проектов, базы данных, токены ботов, деплой клиентских сайтов, система резервных копий и механизм авторизации Mini App.

ОГРАНИЧЕНИЯ
- Для совершенно нового VPS требуется первоначальный доверенный канал доступа: браузерная VNC/Console панель провайдера или поле User Data/cloud-init до первого запуска. Site Control не может сам назначить себе root-доступ к серверу, на котором ещё нет доверенного SSH-ключа.
- Действие root-команды без диалогов намеренно повышает риск ошибочных нажатий. Доступ и аудит команд сохраняются, но техническое выполнение на вашем действующем VPS требует проверки после установки.
