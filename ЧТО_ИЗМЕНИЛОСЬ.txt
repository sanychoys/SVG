SITE CONTROL v1.13 · АУДИТ, СТАБИЛЬНОСТЬ И УПРАВЛЕНИЕ ПРОЕКТАМИ
25.10.2026

1. Доступ в Telegram Mini App
   Одноразовый билет запуска теперь хранится в общей базе Site Control, а не
   только в оперативной памяти одного Python-процесса. Билет действует 90 сек.,
   используется один раз. Право администратора проверяется при использовании.

2. Подключение к VPS
   Подтверждение отпечатка SSH-ключа сохраняется в защищённом служебном
   хранилище, которое доступно всем API-процессам. Временное разрешение
   принадлежит тому администратору, который сканировал ключ; оно одноразовое.

3. Telegram-боты клиентов
   В проекте появилась кнопка «Отключить бота» с подтверждением. Действие
   отзывает webhook в Telegram, отключает запись и удаляет локальный токен.
   Если Telegram не отвечает, операция не выдаётся за успешную.

4. Безопасность удаления проектов
   Нельзя удалить проект с активным ботом или подключённым VPS. Проверка
   зависимостей выполняется до переноса в архив — проект не пропадает из
   списка после неудачной попытки удаления. Файлы на VPS не стираются.

5. Обновление Site Control
   Если задача установки остаётся в очереди более трёх минут, панель
   показывает предупреждение о необходимости проверить updater, вместо
   бесконечного сообщения об ожидании. Версия API обновлена до 1.13.0.

6. Интерфейс
   Понятнее подписаны серверы без привязки к проекту; ненужная кнопка
   «Подготовить VPS» не показывается для таких серверов. Добавлено действие
   отключения клиентского бота. Версии CSS и JavaScript обновлены для кеша.

7. Сохранение данных
   Архив не содержит рабочую базу SQLite, таблицу администраторов,
   приватные SSH-ключи, Telegram-токены и конфигурацию сервера. Второй
   администратор не должен потерять доступ из-за этого обновления.

ВАЖНО: подключение новых серверов, выдача SSH-прав, настройка DNS и HTTPS,
а также системные права на обновление самой платформы требуют корректной
первоначальной настройки соответствующих серверов/провайдера.
