# Site Control v1.7

Обновление для установки через текущий ZIP-установщик Site Control на прежнем VPS.

## Основные изменения

- Бот-админ Mini App: подписанный initData или одноразовый защищённый вход по свежей кнопке `/start` (TTL 90 секунд).
- `/logs`: свежие события, максимум 30 за последние 24 часа, с часовым поясом администратора после входа в панель.
- Веб-логи: локальное время браузера и кнопки «Копировать»/«Скачать».
- Python 3.14: безопасный запуск локальных команд без `preexec_fn`.
- Проверка SSH отпечатков: ED25519, ECDSA, RSA, повторяющиеся записи; без автоматического доверия.
- Обновлённый монохромный интерфейс с доступностью reduced-motion.

## Важно

`config.py`, `admins.json`, базы данных, SSH-ключи, `.env` и прочие приватные данные не включены в ZIP и не должны перезаписываться установщиком.

В текущей архитектуре и Telegram-бот, и FastAPI должны работать в **одном процессе**, поскольку краткоживущие билеты хранятся в памяти. При разделении служб на несколько процессов нужно перенести билеты в общий транзакционный store.

См. `ИНСТРУКЦИЯ.txt`, `АУДИТ_И_ТЕСТЫ.txt`, `FAQ_ПО_ШАГАМ.txt`.

Дизайн ориентируется на чистую визуальную иерархию, навигацию и компактные блоки панели управления, вдохновлённые профессиональными референсами Dribbble. Макеты не копируются напрямую.
