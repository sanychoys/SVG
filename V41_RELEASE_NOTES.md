# SVGTracker V41 — V37 + iPhone Shortcuts

## База и границы изменений
- Основой является оригинальный архив `SVGTracker_V37_MiniApp_Concurrency_Fix.zip`.
- Сохранены без изменений V37: `product.js`, `product.css`, `product_db.py`, `product_api.py`, `intelligence.py`, `insights.py`, `key.py`, `deploy/admin_deploy.py`, `deploy/svgtracker.service`, остальные файлы механизма запуска, тесты и документация.
- Только пять существующих файлов имеют изменения по сравнению с V37: `main.py`, `finance_db.py`, `index.html`, `script.js`, `style.css`. Эти изменения переносят функции настройки iPhone из V38.
- Версия API и cache-busting статических ресурсов установлены в 41.
- **Не переносили V39/V40**: новый сценарий авторизации, загрузки frontend, статический API-прокси и изменения polling. Вход в Mini App — как в V37.

## Новое
- Настройки `Команды iPhone` доступны в `Финансы` и `Профиль → Настройки`.
- Получение одноразово показываемого персонального ключа через Mini App. По умолчанию ключ не создаётся.
- Отзыв и ротация ключа, статус использования, инструкция по `GET /api/shortcut/finance/options` и `POST /api/shortcut/finance/transaction`.
- Доступ к API команд — только по личному Bearer-токену, хеш хранится в базе, сырой токен показан лишь при выпуске.
- Опциональная iCloud-ссылка на опубликованный шаблон через `SVGTRACKER_SHORTCUT_ICLOUD_URL` (пока её нет, кнопка скрыта).
- Бот-команды `/shortcut` и `/shortcut_revoke` остаются доступны.

## Что НЕ изменялось
- Способ определения Telegram Mini App, процессы запуска и systemd, HTML-экран авторизации обычного сайта, база существующих финансов.
- Изменения схемы `shortcut_tokens` не требуются — эта таблица уже есть в V37.

## Установка и диагностика
1. Сделайте резервную копию БД и сохраните конфигурацию сайта. Не удаляйте или откатывайте БД.
2. Загружайте этот ZIP через рабочий механизм деплоя. Текущая ошибка `systemd-run failed` связана с запуском systemd-задачи; этот ZIP сам по себе не чинит работающий установщик и может не устанавливаться, пока ошибка не устранена. При необходимости использовать SSH или ранее рабочую процедуру установки после проверки бэкапа.
3. После обновления `GET /api/test` должен содержать версию 41.
4. Откройте Mini App в Telegram: интерфейс должен запускаться как V37. Проверьте тренировки/финансы, затем `Финансы → Команды iPhone`, выпуск ключа, запись тестовой операции, отзыв ключа.
5. Если после установки виден текст без стилей или экран обычного веб-входа, проверьте, что Nginx отдаёт `/style.css`, `/product.css`, `/script.js`, `/product.js` именно из V41 и что в Telegram присутствует подписанное `initData`.

## Ограничения проверки
Тесты выполнялись локально на изолированной SQLite. Доступа к работающему VPS и Telegram Mini App пользователя нет. Только установка и испытание на телефоне могут подтвердить работу боевого окружения.
