# SVGTracker V40 — восстановление привычного Mini App + iPhone Shortcuts

Основа: интерфейс V38 с сохранением настройки «Команды iPhone»; серверные исправления V39 (включая предотвращение дублирования polling) сохранены. Навязчивая блокирующая проверка загрузки из JS V39 отменена.

## Исправлено

- Внутри Telegram нет промежуточной страницы «Войти в аккаунт» / «Продолжить через Telegram». При обычном запуске открывается приложение; Telegram initData используется автоматически.
- Публичная веб-авторизация сохранена отдельно по адресу `https://starslix.ru/?web=1`. Это предотвращает ошибочный показ страницы входа в Mini App, когда Telegram не передал параметры запуска достаточно рано.
- Главные CSS и JavaScript грузятся через четыре **строго ограниченных** GET-адреса `/api/client/style.css`, `/api/client/product.css`, `/api/client/product.js`, `/api/client/script.js`. Это обходной путь для VPS, где правила Nginx случайно закрыли статические `/style.css` и `/script.js`.
- Если API ещё не раздаёт ассеты, браузер один раз пробует старые статические адреса.
- Обновлены версии ресурсов до V40 и диагностика их доступности.
- Сохранены все возможности V38: Apple «Команды», финансовая аналитика, помощник без нейросетей, автоматизации, поиск, заметки, отчёты и остальные модули.

## Безопасность

- Проверка подписи `initData` на сервере не отключалась.
- Конфигурация Telegram, ключи Shortcut, БД и приватные файлы по новому эндпоинту недоступны. `/api/client/` раздаёт только фиксированные четыре публичных клиентских файла.
- Не следует отключать авторизацию API или публиковать config.py / БД в Nginx.

## После деплоя

1. Сделать резервную копию `/backup` и установить ZIP через `/deploy`.
2. Открыть `https://starslix.ru/api/test` — ожидается `version: "40"`.
3. В браузере проверить адреса `/api/client/style.css?v=40` и `/api/client/script.js?v=40`: должны вернуть 200, с корректными типами CSS/JS. Если API недоступен, нужно сначала устранить проблемы его проксирования в Nginx.
4. Полностью закрыть старый экземпляр Mini App в Telegram и открыть его через кнопку бота. После деплоя должен отображаться привычный главный экран, без страницы входа.
5. Проверить «Финансы → Команды iPhone» и сохранение операции.

> ZIP не меняет Nginx автоматически, не содержит базы данных и приватных токенов. Если Telegram при запуске вообще не передаёт `initData`, сервер не позволит читать персональные данные: надо исправлять источник запуска Mini App, а не отключать проверку подписи.
