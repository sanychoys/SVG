SITE CONTROL v1.17 — ROOT-ДОСТУП

Откройте Site Control → Наша платформа → Консоль. Здесь есть кнопка «Копировать команду» и «Проверить доступ».
Эту команду нужно ОДИН раз вставить в системную веб-консоль VPS-провайдера с телефона (или SSH-клиент).

Если Site Control запущен под Linux root:
cd /var/www/SVG && sudo python3 deploy/configure_root_executor.py --web-user root --owner-id 382257126 --enable-root
sudo systemctl is-active sitecontrol-root-executor.service

Если он запущен под другим Linux-пользователем, пользуйтесь автоматически сформированной командой из интерфейса — там верно указан --web-user.
Root-команды доступны только администраторам с разрешением platform.root, проверяются в API и повторно в отдельной системной службе; действия журналируются.

Root-служба НЕ устанавливается автоматически веб-приложением. Если systemd запрещает запуск служебных процессов, требуется разовая настройка VPS администратором ОС.

Службу можно отключить в веб-консоли провайдера: sudo systemctl disable --now sitecontrol-root-executor.service
