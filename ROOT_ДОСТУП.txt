Site Control v1.18 — ROOT ПРАВА

Владелец (382257126): ROOT-команды с действующими разрешениями выполняются без диалогов подтверждения. Дополнительные администраторы: запрос подтверждения включён по умолчанию, владелец может отключить его в карточке администратора.

Условия выполнения:
- На нашем VPS должна быть активна отдельно установленная служба sitecontrol-root-executor.service.
- На клиентском VPS нужен SSH-вход именно под root по разрешённому ключу либо отдельный эквивалентный привилегированный способ доступа. Site Control сам не активирует root на чужом сервере без доверенной начальной консоли.
- Каждая команда проходит контроль полномочий (права на сервер и проект), исполнение ограничивается временем, операции аудируются.
- Выключение окна подтверждения не отключает проверку Telegram/сессии и не создаёт парольный доступ.

Первое подключение нового VPS полностью с телефона: «Инфраструктура» → публичный SSH-ключ → веб-консоль провайдера → подготовительная команда или cloud-init → сверка SSH-отпечатка → сохранение сервера.
