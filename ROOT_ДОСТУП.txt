SITE CONTROL v1.15 — ROOT И РОЛИ

Полный root-доступ может быть выдан КАЖДОМУ администратору, не только владельцу.
Доступ настраивается в «Администраторы» → «Настроить права».

Главный владелец 382257126 имеет неизменяемые полные права.
Существующие дополнительные администраторы сохраняются после обновления и
по умолчанию имеют режим «Полный доступ», включая root.

«Полный доступ» включает клиентские проекты, root-доступ через SSH при входе
под root, а также root-службу Site Control при отдельной серверной настройке.
«Выборочные права» позволяют выдать root только на конкретные клиентские VPS
или отдельно root на сервер Site Control. Поддерживается ограничение по проектам.

САМОСТОЯТЕЛЬНАЯ ПЕРВАЯ НАСТРОЙКА ROOT-СЛУЖБЫ:
  cd /var/www/SVG
  sudo python3 deploy/configure_root_executor.py --web-user root --owner-id 382257126 --enable-root
  systemctl is-active sitecontrol-root-executor.service

Укажите правильного Linux-пользователя Site Control вместо root, если сервис не root.
Для нестандартного admin state path укажите --roles-dir /path/to/admin-state.
После перехода с v1.14 НАСТРОЙКУ СЛУЖБЫ НУЖНО ПОВТОРИТЬ: ранее установленная
копия исполнителя была ограничена владельцем и не знает о новых правах.

Root-исполнитель сверяет Telegram ID с admins.json и admin_roles.json на каждом
запросе, а также проверяет Linux UID веб-процесса и записывает аудит.
Но компрометация разрешённого веб-процесса потенциально угрожает root-службе:
отдельная root-служба не делает выполнение произвольных команд через Интернет
абсолютно безопасным. Для уменьшения риска ограничьте доступ к панели через VPN.
