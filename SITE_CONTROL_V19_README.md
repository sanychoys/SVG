# Site Control v1.9 — Premium Dark Redesign

Полный редизайн интерфейса существующего Site Control / Telegram Mini App. Бизнес-логика не изменена.

**Scope:** дизайн-система, UI-компоненты, mobile-first навигация, интерфейсы проектов, файлов, консоли, серверов, бэкапов, логов, FAQ и администраторов, анимации и responsive.

**Вне scope:** API, БД, Telegram, Mini App-авторизация, SSH, деплой, изменение значений метрик, любые новые сценарии.

См. `ЧТО_ИЗМЕНИЛОСЬ.txt`, `ИНСТРУКЦИЯ.txt`, `АУДИТ_И_ТЕСТЫ.txt`.
