# SVGTracker V44 — Training Start & Calendar Time

Основа: рабочая сборка V43. Не изменяет стандартную Telegram-авторизацию,
механизм установки, финансовые данные или настройки iPhone Shortcuts.

## Исправлено

1. **Кнопка «Начать тренировку»**: переменная `todayKey` использовалась без
   определения внутри `startWorkout`, из-за чего возникал `ReferenceError` и
   тренировка не запускалась. Дата теперь вычисляется в момент старта.
2. При отсутствии недельного плана основная кнопка запускает **«Свободную
   тренировку»** сразу, без обязательного ввода названия. По желанию можно
   ввести название через кнопку «Указать название».
3. После завершения одной тренировки можно сразу начать следующую через
   «Начать ещё»; кнопка больше не блокируется.
4. Нажатие на день календаря открывает редактор **ручной длительности**:
   название, часы и минуты, сохранение, изменение, удаление. Будущие даты
   не допускаются. Время от 1 минуты до 23 ч 59 мин.
5. Ручная запись — отдельная `completed`-сессия в общей истории с постоянным
   идентификатором `manual_YYYY-MM-DD`. Редактирование не создаёт дубликат,
   не перезаписывает обычные тренировки и обновляет календарь, график недельной
   активности, главную страницу, центр аналитики и ежедневные/недельные отчёты
   после синхронизации.
6. Синхронизация при редактировании вручную выбирает запись по `updatedAt`, а
   не по первоначальной дате завершения. Удалённые записи имеют tombstone
   в `state.sync.tombstones.workouts` и не восстанавливаются от старых копий.

## Обновление с телефона

1. Отправить `/backup` в Telegram-бот и дождаться подтверждения.
2. Отправить этот ZIP через `/deploy`.
3. Дождаться успешного завершения. Проверить `/deploy_status` и
   `https://starslix.ru/api/test` — версия API должна быть `44`.
4. Закрыть предыдущий Mini App полностью и открыть снова из Telegram.
5. Проверить запуск свободной тренировки, завершение и календарную запись.
   После повторного открытия убедиться в сохранении данных.

**Важно:** в архиве нет базы данных, `config.py`, `.env`, пользовательских файлов,
секретов и токенов. Проверки проведены локально; работа на текущем VPS и в
реальном Telegram WebView не подтверждена до установки.
