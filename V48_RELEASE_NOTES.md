# SVGTracker V48 — Читаемая копия данных и несколько администраторов

Основа: V47. Вся существующая логика Mini App, календаря, уведомлений и деплоя сохранена.

## Копия аккаунта

В профиле → «Мои данные» основная кнопка теперь скачивает **HTML-документ**, а не JSON:

- Русские заголовки и понятная таблица по каждому разделу: аккаунт, настройки, уведомления, друзья, тренировки, финансы, расписание, заметки, автоматизации.
- Структурированные записи с сохранением всех существующих данных (за исключением файлов вложений: только метаданные).
- Работает без интернета после скачивания. Можно открыть в браузере / приложении «Файлы» и через функцию «Печать» сохранить PDF.
- Отдельная кнопка скачивает **.txt** для наиболее простого просмотра.
- Существующий API `/api/profile/export` без параметров по-прежнему возвращает JSON для совместимости с автоматизациями; `?format=html` или `?format=txt` возвращает человекочитаемый документ.
- Требуется авторизация владельца. Отдаваемый документ не содержит токенов, ключей, паролей или содержимого вложений. Применены `Cache-Control: no-store` и CSP для HTML. Строки из заметок/событий экранируются.

Важно: файл содержит частную информацию — не пересылайте посторонним.

## Несколько администраторов

### Команды Telegram-бота (в личном чате)

1. Будущий администратор открывает @SVGTrackerbot, нажимает «Start», отправляет `/myid` и передаёт полученный номер действующему администратору.
2. Действующий администратор вызывает `/admin_add 123456789` и подтверждает предоставление прав кнопкой в течение 10 минут.
3. Команда `/admins` показывает всех администраторов.
4. Для отзыва доступа: `/admin_remove 123456789` и подтверждение кнопкой.
5. Панель `/admin` содержит кнопку **«Админы»**.

Все назначенные администраторы получают те же рабочие команды: `/deploy`, backup, rollback, диагностику, мониторинг, GitHub-инструменты, настройку и управление другими администраторами. Подтверждение изменения прав доступно только тому, кто его запросил. Перед каждым действием проверяется актуальность полномочий. Уведомления об ошибках направляются всем текущим администраторам; результаты deploy/rollback — инициировавшему администратору.

Для предотвращения потери управления **первичный администратор, заданный через `SVGTRACKER_ADMIN_ID`**, не удаляется из чата и может восстановить доступ. Самостоятельное удаление своих прав также заблокировано.

Список находится вне публичного каталога сайта: `/var/lib/svgtracker-admin/admins.json` (либо каталог из `SVGTRACKER_ADMIN_STATE_DIR`). Права файла `0600`, изменения атомарные с межпроцессной блокировкой; события выдачи/отзыва заносятся в закрытый `admins_audit.jsonl`. Эти файлы сохраняются при обычном ZIP-деплое, но **не входят в поставляемый ZIP** и должны отдельно входить в полную резервную копию VPS.

Управление администраторами рассчитано на доверенных людей: назначенный человек получает доступ к резервным копиям, деплою и прочим административным действиям. Назначайте только тех, кому полностью доверяете.

## Тесты

- Все существующие тесты V47 + новые тесты экспорта, авторизации и постоянного хранения прав.
- Изоляция выгрузок между аккаунтами; отклонение запросов без авторизации.
- Права в состоянии без файла, после создания и после перезапуска; отзыв; защита владельца; отказ посторонним; проверка чужого callback; параллельные изменения; повреждение файла и безопасное поведение.
- Локальная браузерная проверка основных экранов на 320, 375, 390 и 430 px.
- Проверка `validate_release` установщика V47 и целостности ZIP.

Установка: `/backup`, затем отправьте архив через `/deploy`. После установки `/deploy_check` должен показывать **48**. Не удаляйте production SQLite и конфигурацию. Проверку доставки сообщений Telegram и работу iOS Mini App на реальном VPS необходимо провести после установки.
