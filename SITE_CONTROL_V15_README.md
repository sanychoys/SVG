# Site Control v1.5 — файловые проекты

Этот архив устанавливается через прежний Telegram ZIP-установщик Site Control V1.4. Корень в ZIP — `TRC/` для совместимости с валидатором V48. Рабочие данные администраторов (`/var/lib/svgtracker-admin/admins.json`), база Site Control (`/var/lib/sitecontrol/sitecontrol.db`) и ключи не включены. **Не заменяйте живую базу файловым архивом!**

Инструкция: `ИНСТРУКЦИЯ.txt`. Список изменений: `ЧТО_ИЗМЕНИЛОСЬ.txt`. Аудит: `АУДИТ_И_ТЕСТЫ.txt`.
