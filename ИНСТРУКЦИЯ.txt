SITE CONTROL 1.17 — ИНСТРУКЦИЯ С ТЕЛЕФОНА

ПОСЛЕ ОБНОВЛЕНИЯ:
1. Откройте Telegram Mini App или Site Control в браузере.
2. «Наша платформа» → «Консоль» управляет только сервером, где установлен Site Control.
3. Команды «Обзор VPS», «Нагрузка», «Диск», «RAM», «Процессы», «Сеть» работают без root-службы.
4. Внизу экрана находится переключатель «Режим ROOT». Если он неактивен, нажмите «Копировать команду» в блоке «Первое подключение полного доступа».
5. Откройте с телефона ВЕБ-КОНСОЛЬ у провайдера, которому принадлежит VPS (или SSH-клиент). Войдите в сервер с sudo-доступом, вставьте скопированную команду и дождитесь завершения. Не передавайте пароли Site Control.
6. Вернитесь в Mini App → «Проверить доступ». При активной службе включите режим ROOT; команды подтверждаются отдельно.
7. В Telegram-боте: /start → «Наш VPS · управление». Когда root-служба работает, кнопка «Root-команда» предложит написать однострочную команду и подтвердить её.

ДЛЯ ПЕРВОГО ВКЛЮЧЕНИЯ ЕСЛИ НЕ МОЖЕТЕ ОТКРЫТЬ МИНИ-ПРИЛОЖЕНИЕ:
Откройте WEB-консоль VPS-провайдера с телефона и выполните (на обычном VPS, где Site Control запущен под root):
cd /var/www/SVG && sudo python3 deploy/configure_root_executor.py --web-user root --owner-id 382257126 --enable-root
sudo systemctl is-active sitecontrol-root-executor.service
Если веб-служба работает не под root, имя Linux-пользователя подставляется автоматически в команду из панели.
Если после установки root не активен, проверьте статус в консоли провайдера: sudo systemctl status sitecontrol-root-executor.service --no-pager.

ВНИМАНИЕ: ПЕРВАЯ АКТИВАЦИЯ ROOT НЕ МОЖЕТ БЫТЬ ВЫПОЛНЕНА ИЗ НЕПРИВИЛЕГИРОВАННОГО САЙТА. Это ограничение ОС, а не ошибка кнопки. Приложению нельзя самостоятельно повышать себе привилегии.

КЛИЕНТСКИЕ СЕРВЕРЫ:
Создать проект → «Серверы и SSH» → настроить SSH-ключ → подтвердить отпечаток → подключить к проекту → «Подготовить VPS» → загружать файлы ZIP или отдельно. Команда исполняется под Linux-пользователем, указанным в SSH-подключении; root доступен лишь при разрешённом входе root по ключу на этом сервере.

КЛАВИАТУРА: для закрытия нажмите на пустую область экрана за полем ввода.

ОБНОВЛЕНИЕ: сохраните резервную копию. Если старый установщик отказывается устанавливать ZIP, обратитесь к инструкции восстановления в архиве. ZIP не меняет системные права до своей установки и не обходит ограничения хостинга.

ВЕЗДЕ: выдавайте полные root-права только доверенным администраторам.
