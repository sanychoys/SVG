SITE CONTROL v1.12 — ИНСТРУКЦИЯ С ТЕЛЕФОНА

1. ПЕРВОЕ ОБНОВЛЕНИЕ, ЕСЛИ ZIP НЕ УСТАНАВЛИВАЕТСЯ

Сохраните /backup и скачайте копию отдельно от VPS.
Если текущий бот / сайт не устанавливает ZIP и пишет systemd-run failed:

а) Откройте SSH/SFTP-клиент на телефоне (например, Termius с SFTP).
б) Загрузите архив Site_Control_V112_Server_Management.zip в папку /tmp VPS.
в) Выполните команды на своём VPS:

  python3 -m zipfile -e /tmp/Site_Control_V112_Server_Management.zip /tmp/sc112-unpacked
  sudo python3 /tmp/sc112-unpacked/TRC/deploy/manual_install.py /tmp/Site_Control_V112_Server_Management.zip

г) После успешного запуска Site Control настроьте разовый updater:

  cd /var/www/SVG
  sudo python3 deploy/configure_update_service.py
  systemctl is-active sitecontrol-updater.path

Ожидаемый ответ на последнюю команду: active.
После этого следующие ZIP можно отправлять из Mini App:
«Наша платформа» → «Файлы» → «Проверить файл» → «Установить».

Обновление не трогает sitecontrol.db, admins.json, config.py и токены.
Первый запуск системы на реальном VPS необходимо проверить отдельно.

2. ОБЗОР СВОЕГО VPS

«Наша платформа» → «Консоль» → «Обзор VPS» — CPU, RAM, swap,
диск, uptime, Python, PID и интерфейсы.
Кнопка «Очистить RAM приложения» освобождает память Python-процесса,
но не делает бессмысленное drop_caches и не удаляет память других служб.
Для Linux это безопаснее, чем принудительная очистка системного кеша.

3. КАК ПОДКЛЮЧИТЬ НОВЫЙ КЛИЕНТСКИЙ VPS

- Создайте у хостера VPS (лучше Ubuntu LTS); получите IP, SSH-порт, пользователя.
- Обеспечьте безопасный SSH-вход с телефона; изначально ключ надо добавить
  через панель хостера или SSH к нужному пользователю.
- Site Control → «Серверы и SSH» → получить публичный SSH-ключ.
- На VPS добавьте ключ в ~/.ssh/authorized_keys с правами 600,
  а ~/.ssh — 700. Сверьте SSH-отпечаток с надёжного канала.
- В карточке подключения VPS укажите IP, порт, имя пользователя, проект.
  Поле папки оставьте пустым: создадим папку автоматически.
- Нажмите «Сохранить», затем «Подготовить VPS» в списке.
- На УДАЛЁННОМ VPS появится каталог вида:
  /home/scdeploy/sitecontrol-sites/slug-proekta
- В проекте → «Файлы» загружайте index.html или ZIP и публикуйте на VPS.
  Файлы публикуются именно в удалённый каталог. 

4. КАК ПОДКЛЮЧИТЬ ДОМЕН

- Зарегистрируйте домен НА КЛИЕНТА.
- Проект → «Домены» → добавьте hostname и связанный VPS.
- В панели регистратора укажите DNS A @ → публичный IP VPS.
- Подождите применения DNS; вкладка «Домены» покажет результат проверки.
- Скопируйте предоставленный Nginx-конфиг. На VPS установите его
  с правами администратора; выполните sudo nginx -t, затем reload.
- Настройте HTTPS через certbot/Let's Encrypt на сервере.
- Проверьте сайт по HTTPS и автоматическое продление сертификата.

DNS/HTTPS не настраиваются автоматически без доступа к регистратору и
системных прав Nginx; Site Control не хранит пароли от доменного регистратора.

5. БЕЗОПАСНОСТЬ

- Не храните токены ботов, пароли VPS и ключи в ZIP с исходниками.
- Не давайте обычному веб-процессу неограниченный root-shell.
- Привилегированный updater включается один раз через доверенную SSH-сессию.
- Храните резервные копии вне VPS. Дополнительные администраторы не удаляются.
