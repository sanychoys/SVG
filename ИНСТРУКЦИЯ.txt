SITE CONTROL v1.13 — ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ИСПОЛЬЗОВАНИЮ

УСТАНОВКА
1. Перед заменой сделайте полный серверный бэкап и скачайте его с VPS.
   Одной файловой копии сайта недостаточно для сохранения базы данных.
2. Проверьте, что в действующей системе работает установщик ZIP.
3. Отправьте Site_Control_V113_Audit_Stability.zip боту Site Control как документ
   и подтвердите установку, либо воспользуйтесь «Наша платформа → Файлы».
4. Если установка не стартует и показано «systemd-run denied», не пытайтесь
   многократно отправлять ZIP: необходимо один раз настроить системный
   updater через SSH с правами sudo (см. FAQ в архиве).
5. После перезапуска проверьте /api/test, /start, Mini App, вкладку проектов,
   список администраторов и статус обновления.
6. Второй администратор и текущие данные не переустанавливаются из ZIP.

НОВЫЙ КЛИЕНТСКИЙ ПРОЕКТ — С ТЕЛЕФОНА
1. Проекты → Новый проект → название и короткий латинский идентификатор.
2. Создайте бота у @BotFather. Telegram не позволяет нашему приложению
   самостоятельно регистрировать нового бота через обычный Bot API.
3. В проекте: Telegram → вставьте токен BotFather → Подключить.
4. Для VPS: Серверы и SSH → создайте публичный ключ → добавьте в
   ~/.ssh/authorized_keys целевого НЕ-root пользователя → проверьте отпечаток
   с SSH-консолью самого VPS → подтвердите → сохраните сервер для проекта.
5. Нажмите «Подготовить VPS» — Site Control создаст каталог внутри домашней
   папки SSH-пользователя клиента. Права для Nginx настраиваются отдельно.
6. В проекте: Файлы → загрузите ZIP или отдельный index.html →
   выберите подключённый сервер → Опубликовать.
7. Домены: добавьте имя, сопоставьте с VPS, настройте DNS у регистратора,
   установите Nginx-конфигурацию и HTTPS на целевом VPS.

КАК ОТКЛЮЧИТЬ КЛИЕНТСКОГО БОТА
Проект → Telegram → Отключить бота → подтвердите DISABLE. Сайт и заявки
сохраняются. Бот перестанет принимать события через наш webhook.

КАК УДАЛИТЬ ПРОЕКТ
Сначала отключите активного клиентского Telegram-бота и привязанные VPS.
Затем архивируйте проект и подтвердите его окончательное удаление.
Это действие удаляет карточку и связанные записи в Site Control, но НЕ
удаляет файлы на удалённом VPS и НЕ отменяет DNS у регистратора.

ДОСТУП В MINI APP
Откройте главного Telegram-бота → /start → свежая кнопка Mini App.
Администратору повторная авторизация не нужна. Билет действует 90 секунд.
Посторонние пользователи не могут войти по Telegram ID без подписи/билета.
Если вход не работает, проверьте системное время VPS, работающий токен
главного бота и сообщения в журнале Site Control. Не отключайте проверку.

ЛОГИ И ОБНОВЛЕНИЯ
Вкладка «Логи» показывает последние события и полные ошибки. Есть
«Копировать» и «Скачать TXT». Системные изменения не должны показывать
успешный результат, если отдельный установщик не подтвердил работу API.
Если операция стоит в очереди более 3 минут, проверьте через SSH:
  systemctl status sitecontrol-updater.path --no-pager
  systemctl status sitecontrol-updater.service --no-pager
  journalctl -u sitecontrol-updater.service -n 60 --no-pager

КАК НЕ ПОТЕРЯТЬ ДАННЫЕ
Ежедневно сохраняйте копию SQLite с согласованной транзакцией / sqlite backup,
отдельно файлы проекта, SSH-ключи и секреты. Храните резервную копию вне
основного VPS. Не отправляйте токены и приватные ключи в чат.
