SITE CONTROL v1.15 — ИНСТРУКЦИЯ

ПОДГОТОВКА
1. Создайте резервную копию VPS, приложения, admin-реестра и базы Site Control.
2. Установите ZIP штатным установщиком. Если установщик не работает, примените
   существующую инструкцию ручной установки через SSH. Не перезаписывайте
   /var/lib/sitecontrol и /var/lib/svgtracker-admin.

НАСТРОЙКА ПРАВ
1. Откройте «Администраторы» в сайте или Mini App.
2. Найдите участника и нажмите «Настроить права».
3. Выберите «Полный доступ» — администратор получает такие же рабочие права,
   включая root-команды и все клиентские проекты (владелец остаётся неизменяемым).
4. Для ограниченного доступа выберите «Настроить отдельные разрешения».
5. Отметьте права и нужные проекты. «Все проекты» даёт доступ ко всем клиентам.
6. Нажмите «Сохранить права». Изменения вступают в силу при следующем API-запросе.
   Для удобства обновите Mini App после изменения роли.
7. Снятие всех разрешений закрывает операционные API данного администратора.
   Для отзыва входа полностью используйте «Удалить доступ».

ROOT-ПРАВА
1. Root на клиентском VPS требует SSH-входа под root по доверенному ключу.
2. Root нашего сервера работает через отдельную системную root-службу.
3. После установки ZIP требуется ОДИН РАЗ повторить настройку root-службы,
   чтобы заменить исполнитель v1.14 на v1.15, который поддерживает роли.
4. Из SSH с телефона (Linux User проверьте через systemctl show svgtracker.service -p User --value):
   cd /var/www/SVG
   sudo python3 deploy/configure_root_executor.py --web-user root --owner-id 382257126 --enable-root
   Замените root после --web-user, если сервис работает от другого Linux-пользователя.
5. Убедитесь, что служба активна:
   systemctl is-active sitecontrol-root-executor.service
6. В Mini App откройте «Наша платформа» → «Консоль» и включите ROOT.
   Проверочная команда: id. Для запуска подтвердите словом ROOT.
7. Если у вас нестандартный каталог администраторов, при настройке дополнительно
   укажите --roles-dir ПУТЬ, соответствующий SVGTRACKER_ADMIN_STATE_DIR.

БЕЗОПАСНОСТЬ
Root-команды реально имеют полный контроль над ОС, файлами, службами и данными.
Выдавайте их только доверенным администраторам. Команды не отменяются автоматически.
Обязательно используйте MFA в Telegram, HTTPS, резервные копии и журнал аудита.
Команда отключения root-службы:
   sudo systemctl disable --now sitecontrol-root-executor.service
