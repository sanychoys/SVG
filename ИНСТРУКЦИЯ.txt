SITE CONTROL v1.6 — КРАТКАЯ ИНСТРУКЦИЯ

ПОСЛЕ УСТАНОВКИ
1. Откройте чат главного бота, выполните /start.
2. Нажмите inline-кнопку «Открыть Mini App».
3. Администратор с подтверждённой подписью Telegram должен сразу попасть на главную страницу. В обычном браузере вход через Telegram нужен отдельно.
4. Проверьте «Наша платформа» → «Консоль»: текущий VPS выбирается автоматически.
5. Проверьте «Наша платформа» → «Логи»: откройте журнал, нажмите «Копировать», затем «Скачать TXT».
6. Откройте «Администраторы» и убедитесь, что второй администратор на месте.

ЕСЛИ MINI APP ПОКАЗЫВАЕТ «ДОСТУП ЗАКРЫТ»
1. Убедитесь, что вошли в Telegram правильным аккаунтом. Главный ID: 382257126.
2. Закройте Mini App и откройте его заново через /start главного бота.
3. Нажмите «Повторить проверку». Если ошибка осталась, запомните текст экрана.
4. Откройте журналы сайта/API из другого администраторского аккаунта или через /logs.
5. «Не переданы данные Telegram» — проверьте кнопку Web App и загрузку Telegram SDK в клиенте, публичный HTTPS URL.
6. «Подпись Telegram не подтверждена» — проверьте, что токен BOT_TOKEN соответствует именно тому главному боту, из которого запущено Mini App, и что сервер получает неповреждённую строку initData.
7. «Аккаунт не в списке администраторов» — проверьте фактический Telegram ID в нужном аккаунте и список администраторов. Не обходите проверку вручную.

КЛИЕНТСКИЕ ПРОЕКТЫ
1. «Проекты» → «Новый проект»: название и slug.
2. «Файлы»: выберите один файл или ZIP. Если заменяете только public/index.html — явно укажите этот путь.
3. «Серверы и SSH»: создайте публичный ключ и добавьте его на VPS клиента. Подробности в FAQ.
4. «Файлы»: выберите VPS, подтвердите публикацию.
5. «Консоль»: выберите VPS для команд и просмотрите вывод.
6. «Логи»: просматривайте журнал в окне, копируйте или скачивайте.
7. «Бэкапы»: создайте копию, импортируйте ZIP, восстановите или удалите копию.
8. «Telegram»: подключите токен бота клиента из BotFather.
9. «В архив»: скрыть из списка; «Вернуть» — восстановить из архива; «Удалить навсегда» требует точного slug и предварительного отключения связанного VPS. Файлы на клиентском VPS не удаляются автоматически.

НАША ПЛАТФОРМА
В боковом меню «Наша платформа» → свой VPS и главный бот Site Control. SSH-сервер создавать не требуется. Локальная консоль запускает команды только с правами непривилегированного системного пользователя. Для действий с root-правами потребуется отдельный защищённый механизм администрирования на сервере.

КОМАНДЫ ГЛАВНОГО БОТА
/start — главное меню с кнопкой Mini App.
/status — краткое сообщение о состоянии + вложение с актуальной инструкцией.
/logs — выбор технического журнала.
Меню с командами обновляется при перезапуске службы. Старый список может кешироваться приложением Telegram — при необходимости перезапустите чат/приложение.

УСТАНОВКА
1. Выполните /backup и сохраните копию вне VPS.
2. Отправьте ZIP главному боту как документ.
3. Подтвердите развёртывание.
4. Проверяйте функциональность: /start, Mini App, вторую учётную запись администратора, локальную консоль, логи, создание и архивирование тестового проекта.
5. Если установщик сообщает systemd-run failed, сначала исправьте доступ к systemd по инструкции ВОССТАНОВЛЕНИЕ_ДЕПЛОЯ.txt через SSH. Новый ZIP не может исправить установщик до своей загрузки.
