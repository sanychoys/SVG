SITE CONTROL v1.19 — КРАТКАЯ ИНСТРУКЦИЯ

СНАЧАЛА:
1. Создайте резервную копию Site Control и сохраните вне VPS.
2. Первую установку v1.19 проведите через уже работающего Telegram-бота: отправьте ZIP как документ → «Установить ZIP». В v1.19 бот и веб-панель используют один установщик. Если бот не запускает обновление, используйте инструкцию ВОССТАНОВЛЕНИЕ_ДЕПЛОЯ.txt и SSH с телефона.
3. После установки заново откройте Mini App, проверьте «Команда», затем «Наша платформа» → «Файлы».

КОМАНДЫ VPS:
• Наша платформа → Консоль: управляйте только собственным VPS. Команды владельца выполняются через уже активированную root-службу; подтверждающих окон нет.
• Проект клиента → Консоль: выбирайте его VPS. Команды выполняются по SSH с правами указанного пользователя. Для root требуется SSH-пользователь root и разрешение «Root: клиентские VPS».
• Поле ручной команды очищается сразу после отправки. Результат остаётся в терминале. Сохраняются право доступа и аудит.
• Быстрые команды «Python · версия», «Python · пакеты», «Проверить обновления ОС» НЕ устанавливают системные обновления автоматически. Обновление системного Python на Ubuntu нужно планировать отдельно во избежание повреждения ОС или приложений.

ПРАВА:
«Команда» → участник → «Настроить права». Для полных прав обе ROOT-галочки включены. Для выборочных прав выберите «Настроить отдельные разрешения» и задайте галочки отдельно.

ОБНОВЛЕНИЕ С САЙТА:
«Наша платформа» → «Файлы» → выбрать ZIP → «Проверить файл» → «Установить обновление» → отслеживать статус. Если активна root-служба, применяется независимая системная задача. Если настроен sitecontrol-updater.path, используется системная очередь. База и реестр администраторов не перезаписываются.

БЕЗОПАСНОСТЬ:
Root-права дают полный контроль над сервером; проверяйте введённые команды. Site Control сохраняет журнал действий. Регистрация/подключение SSH и доменов требуют доступа к вашему провайдеру.
