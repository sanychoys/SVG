SITE CONTROL v1.10 — КАК УСТАНОВИТЬ И ПРОВЕРИТЬ

1. Сделайте резервную копию рабочей версии Site Control и сохраните архив вне основного VPS.
2. Отправьте Site_Control_V110_Neon_Blue_Navigation_Fix.zip в действующий механизм обновлений или загрузите архив через «Наша платформа → Файлы».
3. Подтвердите установку. Архив содержит папку TRC/ и совместим с прежней схемой развертывания.
4. Полностью закройте Telegram Mini App, затем откройте заново через кнопку в чате бота. Для сайта обновите страницу. CSS и JS запрашиваются с новой версией sc1100.
5. Проверьте «Проекты»: в четырех карточках показателей нет декоративных квадратов, акцент сине-голубой.
6. Откройте боковое меню: вся панель видна, фон сзади размыт. Нажмите на фон — меню должно уехать. Также можно закрыть через Esc.
7. Откройте «Наша платформа»: переключайте Файлы, Консоль, Бэкапы, Логи, Telegram. Должен показываться только один из разделов; блок обновления отображается только во вкладке «Файлы».
8. На вкладке «Консоль» убедитесь, что поле для ввода команд и окно результата стали выше. Выполнять команды ради проверки оформления не требуется.
9. Откройте «Администраторы» и «Новый проект». Нажмите на поле ввода: должен появиться только один нижний голубой индикатор, без двойной рамки. Некорректное обязательное поле по-прежнему выделяется красным.
10. Если поведение не изменилось, проверьте, действительно ли обновление применилось: в меню указана версия интерфейса V1.10 UI.

Важно: данная версия не исправляет ошибки SSH, токена Telegram или серверного установщика. Она не изменяет данные и административные права.
