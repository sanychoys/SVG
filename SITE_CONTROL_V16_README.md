See `ЧТО_ИЗМЕНИЛОСЬ.txt`, `ИНСТРУКЦИЯ.txt`, `FAQ_ПО_ШАГАМ.txt`, `АУДИТ_И_ТЕСТЫ.txt`, and `ВОССТАНОВЛЕНИЕ_ДЕПЛОЯ.txt`.
