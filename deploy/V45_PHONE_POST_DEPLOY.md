# V45. Проверка обновления с iPhone

1. `/backup` — резервная копия до деплоя.
2. Отправить архив ZIP V45 админ-боту и выполнить подтверждение установки.
3. `/deploy_status` → `success`, `/deploy_check` → API `45`.
4. Открыть https://starslix.ru/api/test и убедиться, что поле `version` равно `"45"`.
5. Закрыть Telegram Mini App целиком, затем заново открыть из бота.
6. Проверить: **Тренировки → Сегодня → Начать**; завершить тренировку; открыть календарь → нажать дату → внести 45 минут → убедиться в пересчёте графика. Изменить длительность, затем удалить только ручное время.
7. Проверить: **План недели** — недельный план сохраняется над разделом разовых изменений.
8. Проверить: **Расписание** — выбрать день, перелистнуть неделю, создать событие; выбранная дата должна перейти в редактор.
9. При ошибке воспользоваться `/logs_frontend`, `/diagnostics`, `/logs_backend`. Не очищать базу.

Работа реального iPhone Telegram WebView подтверждается после установки — локальный Chromium не заменяет эту проверку.
