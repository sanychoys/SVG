# Публикация готовой команды Apple Shortcuts для SVGTracker

Для всех пользователей можно подготовить настоящую готовую команду и опубликовать её через Apple iCloud.

1. На iPhone откройте «Команды». Создайте команду «SVGTracker Финансы» по инструкции внутри профиля SVGTracker. Не вводите в шаблон реальный секретный Bearer-токен.
2. Вместо жёстко заданного токена используйте вопрос при импорте (настройки команды → Setup / Import Questions, если доступно на вашей версии iOS): попросите пользователя вставить индивидуальный ключ. Токен используется только в значении HTTP-заголовка `Authorization: Bearer <ключ>`.
3. Проверьте оба сценария (расход с категориями, доход без категории), корректный JSON POST, локальную дату `yyyy-MM-dd` и отображение `message` из ответа API.
4. Поделитесь командой через Apple «Команды» → «Поделиться» → «Скопировать ссылку iCloud». Убедитесь, что ссылка имеет вид `https://www.icloud.com/shortcuts/<идентификатор>` и действительно открывается на другом iPhone без публикации секретного ключа.
5. На сервере в окружении `svgtracker.service` добавьте `SVGTRACKER_SHORTCUT_ICLOUD_URL=<НАСТОЯЩАЯ_ССЫЛКА>`, обновите unit и перезапустите сервис. Избегайте добавления ссылок и секретов в публичный код.
6. После подключения в Mini App появится дополнительная кнопка «Установить готовый шаблон из iCloud». Пользователь всё равно должен самостоятельно разрешить добавление Shortcut, а также вставить персональный токен.

**Важно:** генерация произвольного `.shortcut` на Linux и отдача пользователям без подписи Apple НЕ гарантирует импорт в iOS. Поскольку действующей опубликованной ссылки у проекта сейчас нет, SVGTracker не выводит фиктивную кнопку установки.

Статус, ключи и отзыв токена работают через существующую таблицу `shortcut_tokens`; ни Bot Token, ни Telegram initData не используются внутри команды iPhone.
