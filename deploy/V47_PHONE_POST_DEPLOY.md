# SVGTracker V47: проверка с iPhone

1. `/backup` → дождись успешного создания резервной копии.
2. Отправь ZIP V47 через `/deploy`, подтверди. `/deploy_status` и `/deploy_check` должны показать success, API v47.
3. Полностью закрой Mini App и снова открой его через Telegram.
4. Главная: секции «Быстро записать» нет; сферы и инструменты доступны.
5. Тренировки: маленький календарь без чисел слева, недельный план справа; нажатие по точке открывает ввод времени, графики обновляются после сохранения.
6. Профиль → Настройки → Telegram-уведомления: переключи категорию, измени число сообщений и интервал; закрой/открой экран — настройка должна сохраниться.
7. Создай событие с напоминанием и настройкой «3 сообщения, каждые 5 минут». Отдельно проверь заметку с одним напоминанием. Повторяющиеся сообщения можно выключить через категории или соответствующую запись.
8. Если всё ещё есть ошибка — `/diagnostics`, `/logs_frontend`, `/logs_bot`. Базу вручную не удалять.
