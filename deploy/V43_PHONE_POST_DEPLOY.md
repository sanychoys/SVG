# V43 — проверка обновления без компьютера

В Telegram отправить `/backup`, затем `/deploy` и файл V43.

После сообщения об успехе:
- `/deploy_check`: API v43 и успешный статус последнего деплоя.
- `/deploy_status`: убедиться в success.
- `https://starslix.ru/api/test`: `status: ok`, `version: 43`.
- Открыть Mini App заново через Telegram; проверить Финансы, Тренировки, Расписание, Заметки, Поиск, Аналитику, Команды iPhone.
- Создать тестовую заметку, изменять её, закрыть и открыть Mini App: текст должен сохраниться.
- Создать расход и проверить наличие его после перезапуска, затем удалить тестовую запись.

При ошибке установки использовать `/deploy_probe`, `/logs_deploy` и `/logs_system`. Если текущая версия уже 43, не отправлять архив повторно. Хранить резервную копию до проверки. Базу не удалять.
