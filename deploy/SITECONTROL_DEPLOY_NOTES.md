# Site Control v1.1 — deploy

Сохраняется текущая `svgtracker.service` и существующая Nginx-настройка V48/v1.0.
В этот релиз включён обновлённый `admin_watchdog.py`, использующий существующий timer.
ZIP обновляет код и статические файлы, не трогая `config.py` и приватную базу Site Control.
Инсталлятор проверяет GitHub, сохраняет backup кода, проверяет `GET /api/test` и откатывает обновление при ошибке.
Главный бот покажет только итог установки (дата, время, число файлов), подробные ошибки сохранятся.
После установки: `/status`, `/last`, `/deploy_check`, проверка сайта и заявок.
