# Проверка V46 с телефона

1. Telegram SVGTracker bot: `/backup`, затем `/deploy` с файлом V46.
2. В `/deploy_check` убедись: API 46, frontend 46, нет ошибок старых JS/CSS.
3. На главной четыре сферы → четыре действия → инструменты.
4. Расход: «Быстро записать → Расход», укажи сумму, сохрани и проверь финансовую историю.
5. Заметка: «Заметка» → создание → сохранение → фильтры и сброс; проверь защиту при закрытии несохранённого текста.
6. Событие: «Событие» → выбор времени → сохранение и повторное открытие; день недели и данные должны остаться.
7. Тренировка: кнопка запуска без плана, завершение и календарь.
8. Профиль: уведомления, приватность, устройство, команды iPhone, отчёты.
9. При проблемах: `/diagnostics`, `/logs_frontend`, `/deploy_status`.

В ZIP нет секретов и базы; штатные API и логика Telegram login не изменялись.
