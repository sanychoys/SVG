Проверки выполнялись только локально, не на реальном VPS пользователя.

- 112 автоматических API/регрессионных тестов: пройдены.
- Веб-проверки Chromium на ширинах 320, 390, 768 и 1440 px: пройдены.
- Опциональные Docker/Nginx команды сообщают об отсутствии программы, а не имитируют выполнение.
- «Наша платформа» не содержит чужих SSH-подключений: проверено на UI с тестовыми данными.
- Неавторизованному/ограниченному админу root-настройки через API недоступны: проверено.
- Корректное сохранение второго администратора в базе: тестовая проверка.
- Закрытие поля ввода при тапе вне поля: проверено.
- Root-кнопка в Telegram проверена статически/по синтаксису, реальная доставка Bot API не проверялась.

ЧТО НЕ ПРОВЕРЕНО НА PRODUCTION:
- Настройки systemd, разрешения root-службы, вход от реального Telegram, удалённые VPS.

СЕРВЕР НЕ САМОВЫДАЁТ ROOT: первоначальное включение только через уже доверенный канал ОС.
