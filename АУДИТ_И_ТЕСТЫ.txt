SITE CONTROL 1.4 — АУДИТ И ПРОВЕРКА
==================================

ПРОВЕРКИ
- Тесты FastAPI: API и авторизация Telegram/сайта.
- Mini App: подпись, основной админ, отказ постороннему, отсутствие
  передачи browser session cookie при входе через Mini App.
- Администраторы: добавление, защита основного владельца, удаление,
  немедленная блокировка ранее добавленного пользователя.
- Сохранена обычная авторизация на сайте по Telegram-коду.
- Изменения/публикация сайтов, клиентские заявки, доступ к SSH и
  остальные 48 регрессионных проверок v1.3.
- Компиляция Python и синтаксическая проверка JS.
- Проверка валидатором архивов V48.

ОГРАНИЧЕНИЯ
- Нельзя проверить права реальной systemd-службы без доступа к VPS.
- Нельзя проверить реальный Telegram Mini App, Telegram Bot API и
  кэш команд iOS до запуска на конкретном сервере.
- Отправка старой службой подробных traceback не изменится ДО деплоя.
- Виджет Telegram «Меню» может обновиться после перезапуска приложения.
- Для авторизации Mini App требуется верный токен главного бота и HTTPS.
- Исторические пути старого установщика остаются, не выполняется
  автоматическая миграция systemd/GitHub.
