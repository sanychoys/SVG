Site Control v1.16 — технический отчёт

ПРОВЕРКИ
- 107 автоматических тестов Python (регрессия 76 + дополнительные 31) пройдены.
- Браузерные тесты Chromium: ширины 320, 390, 768, 1440 px.
- Проверены: загрузка и выбор ZIP, прогресс, состояние успеха, отсутствие ложной доступности установки, переключение 6 быстрых команд и расширенного списка, отсутствие горизонтальной прокрутки.
- Проверены синтаксис Python и JavaScript, защита административных API и подтверждения root-команд (регрессионные тесты).
- Проверена обработка состояния установки без запуска запрещённого systemd-run.
- Полный ZIP сохраняет код прежней v1.15, а не только CSS; состояния проектов и реестра администраторов в архиве отсутствуют.

ВАЖНЫЕ ГРАНИЦЫ ТЕСТА
- Нет доступа к реальному VPS или системному systemd, поэтому фактический перезапуск и установку нельзя считать подтверждёнными.
- Для первой активации обновлений на вашем VPS нужна одна команда через SSH: cd /var/www/SVG && sudo python3 deploy/configure_update_service.py.
- Подготовленные команды для Docker/Nginx требуют наличия этих программ на соответствующем сервере.
- Полное управление root работает только там, где предоставлены права: root по SSH на клиентском VPS или отдельный явно активированный root-executor на нашем VPS.
