SITE CONTROL v1.19 — ЛОКАЛЬНЫЙ АУДИТ

Тестирование на изолированном окружении, НЕ production:
• Актуализированный регрессионный набор + новые тесты API: 135 успешно.
• Python compileall и node --check: успешно.
• Браузерные сценарии в Chromium 320/390/768/1440 px: открытие панели, вкладки консоли, отправка root-команды с немедленным очищением поля, проверка API-запроса, просмотр/редактирование ROOT-галочек администратора; без обнаруженных ошибок JS и горизонтального скролла.
• Мок-контур systemd: ZIP ставится в очередь через root_executor, очередь обновлений через watcher остаётся доступна, неуспешный запуск не помечается успешной установкой.
• Прямая авторизация API: отсутствие root capability блокирует привилегированный запуск; SSH-права также проверены.

НЕ ПОДТВЕРЖДЕНО:
• Системная установка на рабочем starslix.ru, актуальная конфигурация systemd, запуск root-исполнителя, реальные Telegram webhook и клиентские SSH-подключения.
• Обновление Python версии на рабочем Ubuntu (целенаправленно не выполняется одним нажатием).

СОХРАННОСТЬ:
• Файлы config.py, admins.json, admin_roles.json, рабочие DB, приватные ключи и секреты не добавляются в ZIP и не выбираются установщиком для замены.
• Перед обновлением обязательно сохраните внешний резервный архив.
