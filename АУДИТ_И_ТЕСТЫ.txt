SITE CONTROL v1.12 — ЛОКАЛЬНЫЕ ПРОВЕРКИ

Проверено по исходникам:
- Путь загрузки ZIP и переход stage → install; предусмотрена отдельная
  systemd .path/.service схема после разовой настройки.
- SQL-таблица доменов создаётся через CREATE TABLE IF NOT EXISTS;
  существующая SQLite и список Telegram-администраторов не перезаписываются.
- Поля VPS сохраняют привязку к клиентскому проекту; подготовка каталога
  направляется на целевой VPS и требует успешной проверки SSH.
- Действия RAM ограничены собственным процессом приложения.
- Проверка имён доменов, защита от командных инъекций в slug.
- Поля iPhone имеют font-size >=16px.

НЕТ проверки реального VPS/SFTP/регистратора/TLS из этой среды.
Окончательный статус после развёртывания требует отдельной проверки.

Итог: 135 автоматических тестов локально, без падений.
UI проверен в Chromium на ширинах 320, 390, 1440 px:
- переключение вкладок, экран Домены, панель платформы, боковое меню;
- отсутствие ошибок JavaScript и горизонтальной прокрутки;
- текстовые поля font-size >= 16px.
- проверка SSH-каталога эмулирована (нет реального клиентского VPS).
- проверка DNS и HTTPS на реальном домене не проводилась.
- отдельная systemd-служба проверена по конфигурации, не запущена на VPS.
