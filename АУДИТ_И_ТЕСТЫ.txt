SITE CONTROL v1.7 — АУДИТ И ТЕСТЫ

УСТРАНЕННЫЕ ПРОБЛЕМЫ
1. Mini App мог постоянно отклонять Telegram initData без второго подтверждённого способа входа. Добавлен короткоживущий одноразовый билет, выпускаемый только главным ботом подтверждённому админу.
2. Из карточки проекта WebApp-кнопка использовала неопределённую переменную admin_user_id. Исправлено.
3. Локальная консоль падала на Python 3.14 с SubprocessError(preexec_fn). Теперь uid/gid передаются subprocess напрямую.
4. SSH host_scan ошибочно требовал строго одну ED25519-строку. Повторы и прочие нормальные типы ключа обработаны. Ключ не принимается автоматически.
5. /logs и веб-панель показывали устаревшие записи из старого продукта; добавлено ограничение по времени и числу событий, исторические ошибки за пределами суток скрыты в обычном просмотре.
6. Время журналов без указанного часового пояса интерпретировалось неоднозначно. Новые события логируются в UTC и переводятся в локальное время при отображении.
7. Отладочные маршруты удалённого трекера засоряли журнал: лишние ошибки 404 подавлены в операционных логах, сами адреса не восстанавливаются.
8. Цветовые акценты и компоненты конфликтовали между несколькими стилевыми файлами. Добавлена итоговая монохромная тема с безопасным reduced-motion.

АВТОМАТИЧЕСКИЕ ПРОВЕРКИ
- 91 тест pytest пройден: существующие операции, права, хранение ролей и дополнительные проверки v1.7.
- Python compileall: успешно. JavaScript node --check: успешно.
- Браузерная проверка Chromium: 390px и 1440px, проект и панель, ошибок JavaScript и горизонтального переполнения не обнаружено.
- Проверка совместимости ZIP с установленным ранее валидатором: результат записан при упаковке.

ОГРАНИЧЕНИЯ И ВНЕШНИЕ ЗАВИСИМОСТИ
- Реальная Telegram-подпись и токен бота на VPS из этой среды недоступны для проверки. Одноразовый бот-билет проверен локальными тестами.
- Реальная доступность SSH, firewall и Nginx стороннего VPS не может быть подтверждена без доступа к этим серверам.
- Локальная консоль намеренно не root. Журналы systemd могут быть недоступны www-data без отдельной настройки прав.
- Одноразовые билеты хранятся в памяти общего процесса бота/API. При разделении этих компонентов на разные процессы понадобится общее защищённое хранилище билетов.
- Предположение о часовом поясе старых записей: UTC. Новые записи содержат однозначные UTC-метки.
- Для просмотра часового пояса в Telegram сначала откройте веб-панель или Mini App с нужного устройства.

ОСНОВНЫЕ ЗАЩИТЫ СОХРАНЕНЫ
- Админ-права повторно проверяются в API; неизвестный пользователь получает 401/403.
- Одноразовый билет невозможно повторно использовать, он хранится в SHA-256 виде и истекает через 90 секунд.
- После выдачи билета он удаляется из истории URL до сетевых запросов авторизации.
- База данных и реестр дополнительных администраторов не включены в ZIP.
- Неизвестные SSH host keys не принимаются без подтверждения.
