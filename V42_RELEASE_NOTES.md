# SVGTracker V42 — phone-first deploy recovery

**Base:** clean V41 (V37 stable Mini App + iPhone Shortcuts).

## Почему появлялось `systemd-run failed`

Отказ `systemd-run` означает, что бот не смог **подтвердить запуск** отдельной задачи. Это не равнозначно отказу deploy: screenshot показывает позднейший `success`, API OK и успешный push. Ошибка могла относиться к отдельной попытке запуска. Причина на конкретном VPS без журналов неизвестна.

## Что нового в Telegram (только администратор)

* `/deploy_check` — текущая версия API, статус службы и последнего деплоя, архив и GitHub commit.
* `/deploy_probe` — безопасная проверка возможности запуска systemd transient unit командой `true`; приложение и база не меняются.
* При `systemd-run` ошибке ZIP сохраняется до 30 минут, можно повторить запуск из **того же сообщения**, но **только после** проверки `/deploy_check`.
* Имена systemd units уникальны, а `systemctl show` перепроверяет потенциально ложную ошибку `systemd-run`.
* Worker применяет межпроцессную `flock`-блокировку и не позволяет двум деплоям/откатам одновременно менять production. Lockfile намеренно не удаляется.
* Новый запуск из Telegram не блокирует цикл обработки сообщений ботом во время вызова `systemd-run`.

## Действия с iPhone

1. `/deploy_check`. Если статус **success**, API **ok**, версия уже актуальна — повторный deploy не требуется.
2. При сбое `/deploy_probe`, `/logs_system`, `/logs_deploy` и сообщить их содержимое для точной диагностики.
3. ZIP загружать через Telegram как обычно; сначала `/backup`.
4. При ошибке запуска проверить `/deploy_check`, затем использовать **Проверить повторно**, только если предыдущая задача не выполняется/не завершилась успешно.

Ограничение: эти новые команды появятся только **после успешной установки V42**. Если существующий механизм запуска задач на VPS действительно не работает, ZIP сам себя установить не сможет. Нужен действующий бот-деплой или провайдерская веб-консоль VPS.

## Проверка и совместимость

Все прежние функции Mini App V41, серверная проверка Telegram, финансы и Apple Shortcuts сохранены. Нет миграций production SQLite и нет изменения service unit. `config.py`, secrets, SQLite, uploads и venv исключены из ZIP. В финальный архив включён тест `tests/test_v42.py`.
