# SVGTracker V47 — календарь и управляемые уведомления

Основа: V46. Telegram login, серверный API, Shortcuts iPhone, финансы, тренировки и механизм /deploy сохранены.

## Внешний вид

- Главная: удалена секция «Быстро записать» целиком. Карточки сфер и входы в инструменты не изменены.
- Тренировки: компактный календарь без чисел; цветные точки показывают статус, дата сохранена в доступной подписи каждого дня. Нажатие по точке по-прежнему открывает редактор длительности. На мобильных экранах рядом показывается недельный план. Подпись месяца сокращена.

## Telegram-уведомления

- Профиль → Настройки → Telegram-уведомления: категории представлены раскрывающимися группами (тренировки, расписание, друзья, заметки, финансы, отчёты). Главный выключатель по-прежнему отключает доставку всех категорий.
- Расписание: каждое событие может отдельно выбрать первое напоминание, количество сообщений (1–6) и интервал (5/10/15/30/60 минут). «Как в настройках» использует настройки аккаунта.
- Заметки: те же индивидуальные настройки в редакторе заметки. Если дата напоминания выключена, никаких сообщений не отправляется.
- По умолчанию **одно** сообщение, повторов нет. Общие настройки позволяют включить несколько сообщений. Ограничение — 6 сообщений для одного события/заметки. При изменении/удалении записи последующие напоминания пересчитываются/отменяются.
- Тренировки: отдельное добровольное напоминание один раз в день по недельному плану, в выбранное локальное время. Отменённые и завершённые тренировки исключаются. По умолчанию выключено.
- Повторные напоминания проверяются сервером, журнал SQLite предотвращает дубликаты после перезапуска. Просроченные повторные отправки старше двух минут не доставляются пачкой после длительного простоя.
- Сообщения бота сокращены: уведомления о событии, заметке, платеже, долге, тренировке и общих событиях содержат только существенные сведения. Убрана повторяющаяся клавиатура из уведомлений; бот продолжает отвечать на команды как раньше.

## База данных

Только аддитивная миграция в `product_db.init_product_db()`:
- `schedule_events.reminder_repeat_count`, `schedule_events.reminder_repeat_interval` (NULL по умолчанию);
- `notes.reminder_repeat_count`, `notes.reminder_repeat_interval` (NULL по умолчанию);
- типизированные настройки повтора/времени тренировки хранятся в уже существующей JSON-таблице `notification_preferences`.

Существующие записи и файлы не удаляются. Для старых записей действуют настройки по умолчанию (1 сообщение).

## Проверки

- Полный набор unittest и специализированные тесты API: настройки, валидация, 3 напоминания с интервалами, разграничение аккаунтов, отмена категорий, редактирование, журнал дедупликации, тренировки по плану, миграция старых таблиц.
- Изолированные Chromium-сценарии на 320/375/390/430 px: календарь рядом с планом, открытие дня, редакторы событий/заметок, глобальные настройки, отсутствие JS-ошибок и горизонтального переполнения.
- Синтаксис Python/JS, обработчики HTML, валидатор прежнего ZIP-деплоя, целостность архива.
- Не проверено на реальном VPS/iPhone: доставку сообщений через Telegram API, живой Telegram WebView, продакшен-конфигурацию и UI с настоящими пользовательскими данными.

## Установка с телефона

1. В боте — `/backup`, дождись подтверждения резервной копии.
2. Отправь ZIP через `/deploy`, подтверди установку.
3. Проверь `/deploy_check` — API v47 и frontend v47.
4. Перезапусти Telegram Mini App.
5. Профиль → Настройки → Telegram-уведомления: включи нужные разделы, при необходимости установи число сообщений и интервал. Сохранение автоматическое.
6. Для конкретного события или заметки открой редактор и измени параметры напоминаний.
7. Чтобы проверить доставку, создай тестовое событие на ближайшее время, но не более 6 сообщений, и проверь журнал бота.
