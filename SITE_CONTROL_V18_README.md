# Site Control v1.8 — эксплуатационное обновление

Этот архив **заменяет код**, а не хранит секреты, базу данных или администраторов.

## Архитектура

- Наша платформа: отдельный рабочий раздел на текущем VPS.
- Клиентский проект: каталог файлов и Telegram-бот клиента + один или несколько привязанных удалённых VPS.
- Файлы клиентов: загрузка сперва создаёт закрытую промежуточную версию, после подтверждения файлы передаются на указанный удалённый VPS по SSH. Постоянное размещение конечного продукта — на VPS клиента, не на VPS Site Control. На нашем VPS остаётся архив загруженного релиза/бэкапа для управления, пока его не удалят.
- Данные администраторов: вне кодовой папки, не затрагиваются ZIP.

## Как обновить платформу из сайта или Mini App

1. Установите v1.8 через прежний Telegram-бот/проверенный установщик.
2. В браузере или Mini App откройте «Наша платформа» → «Файлы».
3. Выберите готовый ZIP с папкой TRC (или одиночный файл с допустимым путём, например `index.html` или `sitecontrol/web.py`).
4. Нажмите «Проверить файл». Это подготовка, живые файлы не трогаются.
5. Нажмите «Установить обновление», подтвердите операцию и дождитесь состояния `success`.
6. Если `systemd-run` отклоняет запуск — проверьте права существующей systemd-службы и механизм запуска доверенного установщика. UI честно покажет ошибку 503, а не ложное сообщение о публикации. **Не давайте процессу браузерного API неограниченный sudo или root shell.**

Обновление выполняет отдельный systemd job, делает файловую копию заменяемых файлов, обновляет код, перезапускает приложение, проверяет `/api/test` и пытается откатить обновление при ошибке. Если задача не может быть запущена из-за прав systemd, ZIP придётся установить через уже работающий привилегированный установщик.

Домен/DNS/Nginx удалённого сервера по-прежнему настраиваются отдельно: самостоятельное создание сайта в панели не регистрирует домен и не устанавливает приложение без подготовки VPS.

## Удаление клиента

Нажмите кнопку ··· в карточке проекта или удерживайте палец ~0,85 секунды. Подтвердите намерение и введите точный идентификатор проекта. Если к нему подключён VPS, сначала безопасно отсоедините сервер; удаление из панели **не удаляет** публичный продукт на VPS клиента. Заархивированные версии файлов Site Control могут сохраняться на диске для восстановления.

## Telegram

Кнопки меню редактируют текущий экран бота, когда Telegram позволяет это сделать. Документы, логи и уведомления о длительных операциях отправляются отдельно; Telegram не позволяет превратить вложение в текст простым edit_text.

## Запреты и ограничения

- Обновление кодовых файлов не включает внешние SQL-базы, секреты и токены.
- Не загружайте недоверенный код: разрешение на установку только для администраторов.
- Удалённый VPS требует OpenSSH, доверенного host-key, открытого SSH-порта и прав на конкретную папку.
- Без доступа к реальному VPS нельзя гарантировать работоспособность SSH, systemd-run или Nginx. Перед обновлением production делайте внешний бэкап.
